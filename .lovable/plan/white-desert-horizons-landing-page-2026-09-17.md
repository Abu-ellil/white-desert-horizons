# WHITE DESERT HORIZONS landing page

## Direction

- Build a single cinematic, editorial page centered on White Desert Egypt, using deep charcoal, warm ivory, and muted champagne gold.
- Use an elegant serif display face and a restrained sans-serif interface face, with generous space, quiet motion, and accessible contrast.
- Create an original cohesive set of White Desert landscape imagery so the site feels specific and premium rather than template-driven.

## Page structure

- Add a transparent sticky navigation with desktop links, a compact mobile menu, and journey CTA.
- Build the full-height landscape opening, editorial introduction, four experience cards, sunset camping story, differentiators, cinematic gallery, inquiry form, FAQ, final invitation, and minimal footer.
- Keep White Desert Overnight visually dominant; position Black Desert and Bahariya only as complementary excursions.
- Add a persistent mobile booking action and smooth in-page navigation.

## Inquiry experience

- Keep all editable business details, social placeholders, WhatsApp number, experience options, and contact labels in one configuration file.
- Make the inquiry form usable without a backend by composing a prefilled WhatsApp message from the visitor's fields.
- Clearly use a placeholder WhatsApp destination in configuration rather than inventing a business contact.

## Search and accessibility

- Add route-level title, description, Open Graph and Twitter metadata, a self-referencing canonical, and TravelAgency structured data with explicit placeholders for unknown business details.
- Use one H1, semantic sections and landmarks, descriptive image text, visible focus states, keyboard-friendly menu and accordion behavior, and reduced-motion support.
- Include natural coverage for White Desert Egypt, White Desert tours, camping, Black Desert Egypt, and Egypt desert safari without repetition.

## Technical details

- Build reusable React sections and data-driven cards/FAQ content with Tailwind v4 semantic tokens defined in the global design system.
- Use the existing button and accordion components where applicable, and add no authentication, database, or server services.
- Verify the finished page in desktop and mobile viewport sizes, including menu, accordion, form-to-WhatsApp flow, layout stability, and current preview diagnostics.
